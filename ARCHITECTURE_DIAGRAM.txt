━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

COURSE ENDPOINTS
─────────────────────────────────────────────────────────────────────────

GET /api/courses
  ├─ Purpose: Fetch all courses
  ├─ Called by: Homepage (for dropdown), Admin Dashboard
  ├─ Response: Array of course objects
  └─ Example:
     [
       {
         id: 1,
         course_code: "WEB101",
         course_name: "Web Development",
         description: "Learn HTML, CSS, JavaScript"
       },
       {...}
     ]

POST /api/courses
  ├─ Purpose: Create new course
  ├─ Called by: Admin Course Management
  ├─ Request body: {course_code, course_name, description}
  └─ Response: Created course with ID

PUT /api/courses/:id
  ├─ Purpose: Update existing course
  ├─ Called by: Admin Course Management
  ├─ Request body: {course_code, course_name, description}
  └─ Response: Updated course

DELETE /api/courses/:id
  ├─ Purpose: Delete course
  ├─ Called by: Admin Course Management
  └─ Response: Success confirmation

REGISTRATION ENDPOINTS
─────────────────────────────────────────────────────────────────────────

GET /api/registrations
  ├─ Purpose: Fetch all student registrations
  ├─ Called by: Admin Registrations View
  ├─ Response: Array of registration objects
  └─ Example:
     [
       {
         id: 1,
         first_name: "John",
         last_name: "Doe",
         email: "john@example.com",
         phone: "+1234567890",
         date_of_birth: "1990-01-15",
         gender: "male",
         address: "123 Main St",
         city: "Addis Ababa",
         courses: [1, 2]
       },
       {...}
     ]

POST /api/registrations
  ├─ Purpose: Submit new student registration
  ├─ Called by: Homepage Registration Form
  ├─ Request body: {all student fields + course_id}
  └─ Response: Created registration with ID

PUT /api/registrations/:id
  ├─ Purpose: Update student registration
  ├─ Called by: Admin Registrations View
  ├─ Request body: {updated fields}
  └─ Response: Updated registration

DELETE /api/registrations/:id
  ├─ Purpose: Delete student registration
  ├─ Called by: Admin Registrations View
  └─ Response: Success confirmation

COURSES TABLE
─────────────────────────────────────────────────────────────────────────

courses
├─ id (PRIMARY KEY, AUTO INCREMENT)
├─ course_code (STRING, UNIQUE)
├─ course_name (STRING)
├─ description (TEXT, NULLABLE)
├─ created_at (TIMESTAMP, DEFAULT NOW)
└─ updated_at (TIMESTAMP, DEFAULT NOW)

STUDENTS TABLE
─────────────────────────────────────────────────────────────────────────

students
├─ id (PRIMARY KEY, AUTO INCREMENT)
├─ first_name (STRING)
├─ last_name (STRING)
├─ email (STRING, UNIQUE)
├─ phone (STRING)
├─ date_of_birth (DATE)
├─ gender (STRING)
├─ address (STRING)
├─ city (STRING)
├─ courses (ARRAY OF INTEGERS) → References courses.id
├─ created_at (TIMESTAMP, DEFAULT NOW)
└─ updated_at (TIMESTAMP, DEFAULT NOW)

CLIENT-SIDE STATE
─────────────────────────────────────────────────────────────────────────

RegistrationFormSimple Component:
├─ formData: Personal information + course selection
├─ courses: List of available courses
├─ coursesLoading: Loading state for course fetch
├─ formLoading: Loading state during submission
├─ Methods: handleInputChange, handleSubmit, validateForm

Admin Components:
├─ courses: List of courses in management view
├─ registrations: List of student registrations
├─ formData: Currently editing form data
├─ editingId: ID of course/registration being edited
├─ Methods: fetchCourses, handleAdd, handleEdit, handleDelete

DATA FETCHING PATTERN
─────────────────────────────────────────────────────────────────────────

1. Component Mounts
   └─ useEffect hook triggers
      └─ fetchCourses() called
         └─ GET /api/courses
            └─ Response cached in component state
               └─ Re-renders with courses

2. User Submits Form
   └─ handleSubmit() called
      └─ Validation check
         └─ POST to API
            └─ Response received
               └─ State updates
                  └─ Component re-renders
                     └─ Success message shown

3. Admin Modifies Course
   └─ handleEdit() called
      └─ PUT /api/courses/:id
         └─ Response received
            └─ Local state updates
               └─ Courses list refreshes
                  └─ Homepage automatically sees change
                     (via new API call from homepage)
