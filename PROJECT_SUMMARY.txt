🚀 HOW TO USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ADMIN - Manage Courses:
1. Go to http://localhost:3000/admin/courses
2. Click "Add New Course"
3. Enter Course Code (e.g., WEB101)
4. Enter Course Name (e.g., Web Development)
5. Enter Description (optional)
6. Click "Save Course"
→ Course now available for students!

ADMIN - Edit Course:
1. Find course in list
2. Click "Edit"
3. Modify details
4. Click "Save"

ADMIN - Delete Course:
1. Find course in list
2. Click "Delete"
3. Confirm deletion

STUDENT - Register with Courses:
1. Go to http://localhost:3000/
2. Fill personal details
3. Scroll to "Select Courses"
4. Check boxes for desired courses
5. Click "Submit Registration"
→ Registration saved with selected courses!
